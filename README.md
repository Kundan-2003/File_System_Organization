# 📁 File Organization System (Node.js CLI Project)

This is a simple command-line file organization system built using **Node.js**. It provides three core features to help you visualize, organize, and understand your file directory structure.

---

## 🔧 Features

### 1. 📂 Tree View  
Display the structure of a directory in a tree-like format.

**Command:**
node main.js tree <directoryPath>

### 2. 🗂️ Organize Files
Organize files in the specified directory into categorized folders based on file extensions (e.g., media, documents, images, etc.).
**Command:**
node main.js organize <directoryPath>

### 3. 🆘 Help
List all available commands and their usage.
**Command:**
node main.js help
